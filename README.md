# EX: 01 Deep Learning Regression Model

## 📌 Overview
A Deep Learning Regression Model built using PyTorch to predict continuous numerical values from input features.

## 🛠️ Technologies
- Python
- PyTorch
- Pandas
- NumPy
- Scikit-learn

## 🚀 Features
- Data preprocessing
- Neural network regression
- Model training and evaluation
- Continuous value prediction

## ▶️ Usage

```bash
pip install -r requirements.txt
python train.py
```

## 📊 Evaluation
- MSE
- MAE
- RMSE
- R² Score
